# 🏋️ Workout Planner - Планировщик тренировок

Windows Forms приложение для планирования тренировок и трекинга спортивной активности.

## 📋 Функциональность

### Основные возможности:
- **📊 Просмотр планов тренировок** - готовые программы упражнений
- **✅ Трекинг активности** - добавление выполненных упражнений  
- **📈 История тренировок** - просмотр и анализ выполненных упражнений
- **🗑️ Управление историей** - очистка и фильтрация записей
- **💾 Автосохранение** - данные сохраняются автоматически в XML

### Управление историей:
- **Полная очистка** - удаление всей истории
- **Очистка по дате** - удаление записей за выбранный период
- **Удаление одной записи** - через контекстное меню
- **Фильтрация** - просмотр истории за определенный период

## 🛠 Технологии

- **.NET Framework 4.7.2+**
- **Windows Forms**
- **C#**
- **XML Serialization** - для хранения данных
- **LINQ** - для работы с коллекциями

## 🚀 Запуск проекта

### Требования:
- Visual Studio 2019 или выше
- .NET Framework 4.7.2+

### Инструкция по запуску:
1. **Клонируйте репозиторий:**
```bash
git clone https://github.com/YourUsername/WorkoutPlanner.git
cd WorkoutPlanner
```

2. **Откройте решение в Visual Studio:**
   - Запустите `WorkoutPlanner.sln`

3. **Соберите проект:**
   - `Build ? Build Solution` (Ctrl+Shift+B)

4. **Запустите приложение:**
   - `Debug ? Start Debugging` (F5)

```
WorkoutPlanner/
```

## 💻 Использование

### Главное окно (Form1):
- **listBox1** - список планов тренировок
- **listBox2** - упражнения выбранного плана
- **listBox3** - история активности
- **button1** - добавить упражнение
- **button2** - обновить данные
- **button3** - очистить историю

### Форма добавления упражнения (Form2):
- **textBox1** - название упражнения
- **numericUpDown1** - количество подходов
- **numericUpDown2** - количество повторений
- **numericUpDown3** - вес (кг)
- **textBox2** - заметки
- **button1** - сохранить
- **button2** - отмена

### Форма выбора дат (DateRangeForm):
- **dtpStartDate** - начальная дата
- **dtpEndDate** - конечная дата
- **btnOk** - подтвердить выбор
- **btnCancel** - отмена
